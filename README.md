# 🧮 Calculadora Matemática  - ITM

Este proyecto es una aplicación de consola desarrollada en **C#** que realiza operaciones matematicas básicas de forma segura.

## 🚀 Características
- **Validación Anti-Crash**: Utiliza `double.TryParse()` para evitar que el programa se cierre ante errores de entrada del usuario.
- **Seguridad Matemática**: Controla errores de división por cero antes de realizar el cálculo.
- **Estructura Limpia**: Implementa métodos (`static functions`) para la lectura de datos y manejo de errores, aplicando el principio DRY (*Don't Repeat Yourself*).

## 🛠️ Tecnologías Usadas
- **Lenguaje**: C# (.NET 6.0/7.0/8.0)
- **IDE**: Visual Studio 2022
- **Control de Versiones**: Git & GitHub
